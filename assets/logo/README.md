# The yession mark

Everything here is generated by `gen.py` from one description of the object — a blue cube (the
agent) with two green half-depth panels (the people) hugging its near faces, the hairline kerfs
between them forming a Y, seen through a wide pinhole lens and made of a translucent jelly on
black. The design record, and every step that led here, is `docs/brand/README.md`.

    python3 assets/logo/gen.py            # the SVGs
    CHROME=<chromium> python3 assets/logo/gen.py --png   # and the PNGs, through Chromium

The mark and the intro cannot disagree: `logo.svg` is the intro's last frame, built as a static
file from the same code at t = 1. Regenerate everything together; never hand-edit one.

| file | what it is for |
| --- | --- |
| `logo.svg` | The mark, for black and dark surfaces. 64-unit box; the object sits in it with 7 units of air so the bloom has room. Pure SVG 1.1: paths, gradients, clip paths and filter primitives, no script, no raster. |
| `logo-light.svg` | The mark for paper and light surfaces. Same geometry; the body is denser (0.82 over 0.55) because white no longer darkens its middle, and the bloom is all but gone (0.1 against 0.3), because a glow that is light on black is a smudge on white. |
| `lockup.svg`, `lockup-light.svg` | The mark beside the wordmark — `yession` in Noto Sans 300 at −0.02em, cut to paths from the face the product ships so the file carries no font. A step heavier than the product's 200 wordmark, because beside a mark this dense the 200 read thin; no full stop. The x-height band is centred on the mark's optical middle. |
| `logo-16.svg` | The mark for 16px: the same object with the kerfs cut three times wider so the Y survives a quarter-pixel, flat faces in the diffuse shading, no filter (one has no room to work at that size). Use it as the SVG favicon and for anything under 24px. |
| `favicon-32.png`, `favicon-16.png` | `logo-16.svg` rasterised, for a browser that takes only PNG. |
| `icon.svg` | The app icon: the mark on the product's black in a 1024 box, corners at 22% (a platform masks its own shape over this anyway), the mark at 72% so the bloom has its room. |
| `icon-1024.png`, `icon-512.png`, `icon-192.png`, `icon-180.png` | The icon rasterised: the manifest's sizes, and 180 for `apple-touch-icon`. iOS takes only PNG for a home-screen icon. |
| `intro.svg` | The mark's intro, 2.4s, one SVG, no script: a top-down view of the agent as a solid blue diamond that turns to jelly where it stands — its bottom edges showing through, so it is a block before it moves — then the camera pulling up and back into the wide lens while the collaborators slide in. SMIL with the easing (CSS ease-in-out) baked into 49 keyframes; click to replay. SMIL cannot read `prefers-reduced-motion`, so a page that respects it shows `logo.svg` instead. About 130 KB, 20 KB gzipped. |

Colours, for anything that has to match the mark without embedding it: blue `#1ba1e2`, green
`#a8dd00`; each runs to a hotter self, never to white — `#6fd8ff`, `#d8f54a` — and to a deep
`#0f6ea3`, `#6f9a00`. These are the product's `--color-blue` and `--color-green`.
